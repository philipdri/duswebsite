# DUS Arkitekter Website

Official website for DUS Arkitekter, built with Next.js 14+, TypeScript, and Tailwind CSS.

## Live Site
[dusarkitekter.no](https://dusarkitekter.no)

## Tech Stack
- [Next.js](https://nextjs.org/) 14+ (App Router)
- TypeScript
- Tailwind CSS
- Adobe Typekit (classico-urw font)
- Ionicons

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## Build

```bash
npm run build
```

## Project Structure
See [ARCHITECTURE_GUIDE.md](./ARCHITECTURE_GUIDE.md) for detailed documentation.

## Deployment
The site deploys to GitHub Pages (or Vercel) automatically. The `CNAME` file configures the custom domain `dusarkitekter.no`.
